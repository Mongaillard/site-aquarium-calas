## 🏰 Âge des Empires Mobile

Un jeu de stratégie temps réel façon Age of Empires, jouable au doigt dans le
navigateur : [`jeu/`](jeu/) — [documentation et règles](jeu/README.md).

```bash
cd jeu && npm start     # puis http://localhost:8080
```

Aucune dépendance, aucune image : tout est dessiné au code. Installable sur
l'écran d'accueil d'un téléphone et jouable hors ligne.
